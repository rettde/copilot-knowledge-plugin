# Privacy

## What This Plugin Does

Compound Knowledge is a set of prompt files for GitHub Copilot. It provides reusable workflows for knowledge work.

## Data Handling

- **No data collection.** This plugin is a set of markdown prompt files. It does not collect, transmit, or store any data.
- **Local only.** All knowledge files (`docs/knowledge/`) are stored locally in your project directory and tracked by git.
- **No external services.** The plugin does not connect to any external services beyond what GitHub Copilot itself uses.
- **No telemetry.** There is no analytics, tracking, or telemetry of any kind.

## What Gets Stored

The only files this plugin creates are:
- `plans/*.md` — Plan files in your project
- `docs/knowledge/*.md` — Knowledge entries in your project

These are plain markdown files under your control, in your repository, tracked by your git history.

## GitHub Copilot's Privacy

This plugin operates within GitHub Copilot. For Copilot's privacy practices, see [GitHub Copilot Privacy](https://docs.github.com/en/copilot/overview-of-github-copilot/about-github-copilot-individual#privacy).
