# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

This project is a set of markdown prompt files with no executable code, no dependencies, and no external service connections. The attack surface is minimal.

If you discover a security concern:

1. **Do not** open a public issue
2. Email the maintainer directly
3. Include a description of the concern and steps to reproduce

## What This Project Contains

- Markdown files (`.prompt.md`, `.md`) — prompt templates and documentation
- No executable code
- No package dependencies
- No API keys or secrets
- No external service integrations
